# ทีมงาน AI 5 ตำแหน่ง — คู่มือใช้งาน

ทีมนี้ไม่ใช่แค่คำอธิบายบทบาท แต่เป็น **subagent ที่ติดตั้งจริงแล้ว** ในโปรเจกต์นี้
ไฟล์นิยามอยู่ที่ `.claude/agents/` แต่ละตัวมีระบบคำสั่ง ทักษะ ข้อห้าม และรูปแบบผลงานของตัวเอง

คุณคือ CEO ทีมรายงานกลับหาคุณเสมอ และ **ไม่มีตัวไหนเรียกตัวอื่นเองได้** เพื่อให้คุณคุมงบเวลาและคุมคุณภาพได้ทุกจุดส่งต่อ

---

## ทีมงานและหน้าที่

| ตำแหน่ง | ชื่อที่ใช้เรียก | รับผิดชอบ | ส่งมอบอะไร |
|---|---|---|---|
| ครูพี่เลี้ยง & นักออกแบบหลักสูตร | `chief-education-officer` | โครงสร้างบทเรียน เนื้อหาใบงาน คำสั่งโจทย์ เฉลย แผนการสอน แบบทดสอบ เกณฑ์ให้คะแนน | สคริปต์เนื้อหาใบงาน L1–L5 + เฉลย + ตัวชี้วัดที่แมป |
| นักพัฒนาเกม & สื่อ Interactive | `edtech-developer` | เปลี่ยนเนื้อหาเป็นเกมเว็บ ระบบคะแนน เสียง UI สำหรับเด็ก ชุดข้อมูล Quizizz/Kahoot | ไฟล์ HTML ไฟล์เดียวเปิดเล่นได้ทันที |
| ศิลปิน & นักเจนภาพ AI | `visual-prompter` | ภาพขาวดำประหยัดหมึกสำหรับใบงาน ภาพสีสำหรับเกม ภาพปกโฟลเดอร์และโพสต์ | Prompt ภาษาอังกฤษฉบับเต็ม + Style Lock + จุดที่ต้องตรวจ |
| นักการตลาด & Copywriter | `growth-marketer` | บทคลิปสั้น โพสต์ Facebook แคปชันแจกของฟรี แผนคอนเทนต์ | บทคลิปแยก Hook/เนื้อหา/CTA/ภาพที่ต้องถ่าย + โพสต์พร้อมลง |
| แอดมินปิดการขาย & ดูแลลูกค้า | `chat-sales-admin` | สคริปต์แชต แก้ข้อโต้แย้ง ติดตามเคสเงียบ ส่งมอบสิทธิ์ FAQ | บทสนทนาพร้อมใช้ ระบุเวลาส่งของทุกข้อความ |

## วิธีเรียกใช้

**แบบที่ 1 พูดชื่อตำแหน่งตรง ๆ** — วิธีที่ใช้บ่อยที่สุด

```
ให้ chief-education-officer ออกแบบหน่วย Feelings สำหรับ ป.2 ครบ 5 ระดับ
```

**แบบที่ 2 บอกงาน ไม่ต้องบอกชื่อ** — ระบบจะเลือกตำแหน่งที่ตรงที่สุดให้เอง เพราะแต่ละไฟล์เขียน description ไว้ให้จับคู่งานได้

```
ช่วยเขียนบทคลิปสั้น 3 ตัวเรื่องเกมใหม่หน่อย
```

**แบบที่ 3 สั่งทั้งสายพาน** — สั่งครั้งเดียว จบทั้งหน่วย

```
เปิดสายพานผลิตหน่วย Feelings ป.2 ให้ครบตั้งแต่เนื้อหาจนถึงคอนเทนต์เปิดตัว
```

## สายพานงานมาตรฐาน

```
        ┌─────────────────────────────┐
        │  chief-education-officer    │  ออกแบบหน่วย + เนื้อหา + เฉลย
        └──────────┬──────────────────┘
                   │ HANDOFF: EDTECH        HANDOFF: VISUAL
         ┌─────────┴─────────┐        ┌─────────────────────┐
         ▼                   │        ▼
┌──────────────────┐         │  ┌──────────────────┐
│ edtech-developer │◄────────┴──│ visual-prompter  │  ภาพประกอบทั้งชุด
└────────┬─────────┘   ภาพเกม   └──────────────────┘
         │ HANDOFF: MARKETING
         ▼
┌──────────────────┐
│ growth-marketer  │  บทคลิป + โพสต์ + แคปชันแจกของฟรี
└────────┬─────────┘
         │ แจ้งว่าคนจะทักมาด้วยคำว่าอะไร
         ▼
┌──────────────────┐
│ chat-sales-admin │  สคริปต์ปิดการขายที่ตรงกับคอนเทนต์ตัวนั้น
└──────────────────┘
         │ คำขอหัวข้อใหม่จากลูกค้า
         └──────────► กลับไปที่ chief-education-officer (วนรอบถัดไป)
```

จุดสำคัญคือ **บล็อก HANDOFF** ทุกตำแหน่งต้องปิดงานด้วยบล็อกนี้ ระบุให้ชัดว่าอะไรส่งต่อให้ใครและต้องการอะไร
คุณอ่านบล็อกนี้แล้วตัดสินใจว่าจะเดินต่อหรือหยุด

## ใบสั่งงานมาตรฐาน

ยิ่งใบสั่งงานชัด ผลลัพธ์ยิ่งไม่ต้องแก้ ใช้โครงนี้ทุกครั้ง

```
ตำแหน่ง : chief-education-officer
งาน     : ออกแบบหน่วย Feelings ระดับ ป.2
ข้อจำกัด: คำศัพท์แกน 8 คำ ใบงานขาวดำ พิมพ์ได้บน A4 หน้าเดียว
ผลลัพธ์ : เนื้อหา L1-L5 + เฉลย + ไอเดีย Active Learning ระดับละ 1 อย่าง
กำหนดส่ง: รอบผลิตวันเสาร์นี้
```

## สูตรสั่งงานที่ใช้บ่อย

**1. ผลิตหน่วยใหม่ทั้งหน่วย**
```
เปิดสายพานหน่วย [ชื่อหน่วย] ชั้น [ป.x]
เริ่มจาก chief-education-officer แล้วรายงานบล็อก HANDOFF กลับมาให้ผมเลือกว่าจะทำเกมระดับไหนก่อน
```

**2. เติมของประจำเดือน (วันที่ 1 และ 16)**
```
รอบเติมของเดือนนี้ ให้ chief-education-officer ทำ 2 หน่วย
edtech-developer ทำเกม 2 ตัว
growth-marketer ทำโพสต์ประกาศของใหม่ 1 โพสต์
สรุปเป็นเช็กลิสต์ให้ผมกดทำทีละข้อ
```

**3. ยอดขายตก ต้องหาสาเหตุ**
```
เดือนนี้คนทัก 200 แต่ปิดได้ 8 คน
ให้ chat-sales-admin วิเคราะห์ว่าสคริปต์แชตหลุดตรงไหน
แล้วให้ growth-marketer ดูว่าคอนเทนต์ดึงคนผิดกลุ่มหรือเปล่า
```

**4. เปลี่ยนใบงานเก่าให้เป็นเกม**
```
ให้ edtech-developer อ่านไฟล์ใบงานหน่วย [x] แล้วทำเป็นเกมเว็บไฟล์เดียว
ใช้กติกาเดียวกับ products/G1-U05-Animals/interactive/index.html
```

**5. เตรียมเปิดรอบขาย**
```
รอบผู้ก่อตั้งจะเปิดวันที่ 25
ให้ growth-marketer ทำคอนเทนต์นับถอยหลัง 3 วัน
และ chat-sales-admin เตรียมสคริปต์รับคนทักช่วงเปิดรอบ
```

## กติกาที่ทั้งทีมยึดร่วมกัน

- **ห้ามแต่งตัวเลข** ยอดสมาชิก จำนวนที่นั่งที่เหลือ และรีวิว ต้องเป็นของจริงเท่านั้น ถ้ายังไม่มีให้เว้นช่องไว้เติม
- **ห้ามสัญญาสิ่งที่คลังยังไม่มี** ทุกคำโฆษณาต้องชี้ไปที่ไฟล์ที่มีอยู่จริงได้
- **ทุกใบงานต้องมีเฉลย** ไม่มีข้อยกเว้น
- **ห้ามใช้ตัวละคร โลโก้ หรือสไตล์ที่มีลิขสิทธิ์** ในทุกชิ้นงานที่นำไปขาย
- **ห้ามเก็บข้อมูลเด็ก** เกมและสื่อทุกตัวต้องเล่นได้โดยไม่ต้องล็อกอิน
- **ภาพเด็กในคลิป** ต้องขออนุญาตผู้ปกครองและเบลอใบหน้าเสมอ
- **ทุกตำแหน่งรายงานกลับหา CEO** ห้ามเรียกตำแหน่งอื่นเอง
